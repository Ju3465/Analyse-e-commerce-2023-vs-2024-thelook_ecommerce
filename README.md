## E-commerce Data Analysis Project

This project analyzes e-commerce performance data to identify key revenue drivers, customer behavior, and profitability trends.

---

## Objectives
- Analyze revenue and margin performance  
- Understand customer behavior and retention  
- Evaluate the impact of return rates on profitability  
- Build clear, decision-oriented dashboards  

---

## Tools & Technologies
- **Python (pandas)** for data analysis and data quality checks  
- **SQL (BigQuery)** for KPI validation and data extraction  
- **Power BI** for interactive dashboards and reporting  

---

## Key Features
- KPI tracking: **revenue, margin, return rate, customer retention**  
- Year-over-year performance comparison  
- Category and geographic performance analysis  
- Visual analysis of profitability vs return rate trade-offs  

---

## Key Insights
- Revenue growth was mainly driven by **order volume**  
- Customer retention declined, highlighting **CRM opportunities**  
- Return rates (~25%) significantly impact profitability  
- Strong long-tail distribution across categories and regions
